# 连续解析逆运动学解选择

## 目的

两连杆平面机械臂的解析逆运动学通常会为同一个可达目标返回两组候选姿态，分别对应不同的肘部构型。逐点独立选择候选解可能使连续目标轨迹出现不必要的关节角跳变。continuous_ik.py 提供一个轻量级候选解选择器，用于在连续轨迹中优先选择靠近上一时刻关节姿态的解。

该模块是轨迹级解选择策略，不改变解析逆运动学本身，也不替代关节限位检查、可达性判断或数值逆运动学。

## 算法

函数 select_continuous_ik_solution(candidates, previous) 接受候选关节角序列和上一姿态：

1. 候选集为空时返回 None。
2. 将候选集转换为 NumPy 浮点数组，并检查其形状为 (候选数量, 2) 且全部为有限数。
3. 如果没有上一姿态，返回第一组候选解的副本，保持解析求解器的候选顺序。
4. 检查上一姿态为包含两个有限关节角的向量。
5. 对每个候选关节角，按每个关节的 2π 周期，将角度展开到上一姿态附近。
6. 计算展开后候选解与上一姿态的欧氏距离，返回距离最小候选解的副本。

核心角度展开为：

\[
\tilde{q}_{i}=q_i+2\pi\,\mathrm{round}\left(\frac{q_{\mathrm{prev}}-q_i}{2\pi}\right)
\]

选择规则为：

\[
q^*=\underset{\tilde{q}}{\arg\min}\;\|\tilde{q}-q_{\mathrm{prev}}\|_2
\]

## 重要行为与限制

- 输入候选解可以是普通序列，也可以是二维 NumPy 数组；空候选集返回 None。
- 候选解与上一姿态必须恰好包含两个有限关节角，非法形状或 NaN/Inf 会抛出 ValueError。
- 输出是新数组，不会直接返回候选输入数组的视图。
- 没有上一姿态时选第一组解；之后按局部关节空间距离选择。
- 该策略不保证始终保持指定的肘部构型。如果不同分支在关节空间中更接近上一姿态，选择器可能切换分支；本策略也不执行关节限位筛选。
- 在奇异位形附近，两组解析解可能合并，分支标签与角度符号不一定足以表示所有连续性行为。
- 选择器只根据相邻姿态作局部决策，不保证全局最优轨迹、速度/加速度约束满足或真实机械臂可执行性。

调用方应先检查解析逆运动学的可达性和候选解，再将选出的姿态作为下一采样点的 previous。如果应用需要强制肘部构型、关节限位或运动约束，应在上层显式实现并测试相应策略。
