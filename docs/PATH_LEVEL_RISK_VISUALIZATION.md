# 路径级风险可视化

## 目的

将现有目标扰动、逆运动学分支稳定性和工作空间可达性压力测试结果，整理为可离线打开的交互式 HTML 看板。该工具仅做研究分析，不修改桌面应用或 IK 算法。

## 输入与输出

输入：数据与实验/奇异位形附近DLS基线实验/目标扰动分支与可达性压力测试_可达初值扩展/逐点结果.csv（96 组序列、11,616 条逐点记录）。

运行命令（在项目根目录执行）：

    .\.venv\Scripts\python.exe ".\代码与仿真\数学原型\visualize_ik_path_risk.py"

输出目录：数据与实验/奇异位形附近DLS基线实验/路径级风险可视化/

- 路径级风险分析.html：离线交互看板。
- 路径级风险逐点标签.csv：每个采样点的风险等级与标签。
- 路径级风险分组汇总.csv：按工况、方法和重复编号汇总的指标。

## 交互内容

- 切换目标扰动、近奇异分支和混合可达性测试工况。
- 切换现有 DLS / 自适应 DLS 和重复编号。
- 查看末端目标 XY 路径；点的颜色对应风险筛查等级。
- 查看最小奇异值、关节步长、末端误差和关节角沿路径的变化。
- 查看触发风险标签的采样点及其索引、误差、奇异值和关节步长。

## 风险筛查规则

- **红色（critical）**：目标几何不可达、IK 未收敛，或实际末端误差大于 1e-6 m。
- **橙色（high）**：最小奇异值不高于 0.02，或关节步长达到稳健离群阈值。
- 关节步长离群阈值为 max(0.15 rad, median + 6 × 1.4826 × MAD)。
- 肘部角符号变化作为单独标签显示。

以上是透明的启发式诊断规则，不是安全认证或物理限值。绿色仅表示当前规则没有触发标签，不代表路径已经证明安全。当前数据来自合成仿真；计算耗时会受运行环境影响。可视化默认使用所选重复序列，分组汇总 CSV 保留所有重复数据。

## 验证

- 单元测试覆盖正常点、近奇异点、不可达目标、末端误差超限、分支符号变化、汇总计数与 HTML 模板生成。
- 看板生成脚本和测试脚本均执行 Python 编译检查。

## 风险标签有效性验证

运行以下命令可对扩展实验的 96 组、11,616 个逐点记录进行独立核验，不会修改输入 CSV 或桌面应用：

    .\.venv\Scripts\python.exe ".\代码与仿真\数学原型\path_risk_validation.py"
    .\.venv\Scripts\python.exe ".\代码与仿真\数学原型\write_path_risk_validation_report.py"

输出新增：

- 路径风险逐点验证.csv：独立事件标记、奇异值、关节步长和分级。
- 路径风险工况验证.csv：按工况、方法和重复编号的汇总。
- 路径风险阈值敏感性.csv：不同奇异值阈值的标记数量及与可达点求解失败事件的对照。
- 路径风险标签有效性验证.md：结果、局限与后续实验建议。

扩展数据现包含 96 组、11,616 个逐点记录，其中 11,396 个目标几何可达，观察到 1,331 个可达点求解失败事件。奇异值阈值 0.02 的点级 Precision 为 29.89%、Recall 为 63.64%；阈值提高至 0.03 时覆盖所有已观察失败点，但 FP 增至 3,387。失败集中于固定参数自适应 DLS 在近工作空间边界路径上的部分随机初值序列；该结果仅适用于当前合成路径和初值分布，不能外推为普遍算法优劣。分支测试已修正为由正运动学生成目标，生成关节路径的第二关节角从 +18° 连续变化到 -18°，中点为 q₂=0°；但两种初始分支、两种方法、三次重复共 12 条序列仍未观测到求解器肘部符号变化。这说明目标路径跨过伸直奇异位形，不等于数值解实际翻支，分支切换能力仍未被该实验验证。关节步长离群和近奇异标签仍属于启发式诊断，不是安全限值。
