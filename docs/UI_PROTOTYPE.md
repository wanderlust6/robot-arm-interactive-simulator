# 首版桌面界面原型说明

## 目标

验证“中央工作区直接操作机械臂，属性面板同步显示和编辑参数”的核心交互。当前原型不承担完整仿真、轨迹编辑或实验管理功能。

## 界面结构

- **顶部工具栏**：重置姿态、设置连杆数量并应用。
- **中央工作区**：显示坐标网格、基座、连杆、关节、末端和目标位置；支持选择对象、拖动关节/末端，并通过鼠标滚轮缩放视图。
- **右侧属性面板**：编辑各段连杆长度和各关节角限位。
- **关节状态浮窗**：显示选中节点的位置、绝对角度，并允许固定或解除固定（基座始终固定）。
- **状态栏与状态面板**：显示求解结果及约束状态。

## 姿态与参数约定

1. 模型支持 1–12 段平面串联转动关节机械臂。
2. 内部关节角使用弧度，采用相对角定义；界面限位以度显示。
3. 初始模型为三段、每段长度 1.0，初始相对角为 `+90°、-90°、+90°`，对应连杆绝对方向“上、右、上”。
4. 重置姿态会恢复交替阶梯：相对角依次为 `+90°、-90°、+90°、-90°……`。
5. 调整连杆数量时保留已有参数；新增连杆长度默认为 1.0，新关节限位默认为 ±180°，新关节角按交替阶梯初始化。
6. 工作区缩放围绕鼠标指针所在的世界坐标进行，避免缩放时目标位置在屏幕上无故漂移。

## 交互约定

1. 修改连杆长度后，按新的几何参数更新末端位置。
2. 拖动末端目标时，调用数值逆运动学；不可达或无法满足关节限位时，保留上一有效姿态并显示原因。
3. 多段模型拖动中间关节时，通过上游关节求解实现节点位置跟随，并尽可能保持固定节点、连杆长度及未参与求解部分的姿态约束。
4. 两段模型保留肘关节固定直线拖动：拖动开始时记录末端方向，拖动期间保持该方向，并满足连杆长度与关节限位。
5. 固定节点只约束其空间位置，不直接锁定对应关节角。
6. 正常可达、奇异边界和无效目标分别提示；状态同时用文字说明，不只依赖颜色。

## 技术选择

- PySide6 提供主窗口、工具栏、可停靠属性面板和参数控件。
- 自定义 QWidget 与 QPainter 绘制二维工作区。
- NumPy 负责数值数组，运动学和约束求解复用 `数学原型` 目录中的模块。
- 滚轮缩放、鼠标拖动与数值求解由工作区和主窗口分工处理。
- 后续曲线显示再评估 PyQtGraph；当前不提前引入曲线依赖。

## 当前不包含

轨迹编辑、仿真时间播放、数据曲线、数据导出、场景保存/加载、负载对象、动力学、碰撞检测和三维视图。
