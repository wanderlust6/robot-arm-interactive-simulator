## 3. 与研究目标最相关的三个发现

### 发现 A：DLS 已经存在，但“使用 DLS”不等于“解决奇异性问题”

数学原型的 numerical_ik.py 中 solve_n_link_ik 已使用 J.T @ solve(J @ J.T + damping² I, error) 的阻尼最小二乘形式，并限制单次关节更新的范数。当前阻尼会根据候选误差是否改善而调整，但不是根据雅可比奇异值/条件数明确调节。

因此，后续研究不能把“首次实现 DLS”当作创新点。更合适的问题是：当前 DLS 在哪些场景下失败或表现不佳？奇异值感知的阻尼、步长策略或路径调整，是否能在成功率、末端误差、关节运动峰值和计算成本之间取得可量化的改善？

### 发现 B：奇异性目前主要用于状态分析，而非轨迹规划决策

轨迹规划器沿给定路径连续求 IK，验证收敛、末端误差、关节限位和时间参数化后的运动约束；当前未将最小奇异值或条件数作为规划接受/拒绝、路径修改或阻尼选择的显式依据。

因此，当前计划应把“奇异性监测”与“奇异性规避/缓解”分开记录，后者属于待研究和验证的功能。

### 发现 C：规划器的失败信息是起点，不是完整的诊断结论

规划器可返回未收敛、限位冲突或运动指标超限等信息，但这些原因未必互斥。例如路径几何不可行、逆运动学局部收敛失败、静态重力力矩超限和时间搜索不足，需要区分。下一步应构造可复现的失败案例，验证系统能否正确区分这些原因，而不是先增加更多 UI 标签。

## 4. 第一轮审查结论

项目已具备研究原型所需的主要基础组件：运动学、解析与数值 IK、初版轨迹规划、理想动力学、约束检查、奇异性指标和实验包。

但当前最缺的不是另一个界面功能，而是研究证据链：

1. 定义一组固定且有代表性的测试场景；
2. 固定当前方法作为基线；
3. 明确每个场景的评价指标与成功判据；
4. 记录失败原因与复现参数；
5. 再提出一项算法改进，并在相同条件下进行对照实验。

建议第一个小实验围绕二维平面机械臂的奇异位形附近 IK 展开，先比较现有 DLS 的表现，不急于直接修改算法。需先明确“接近奇异”的量化定义、目标路径、初始姿态、限位、阻尼设置和误差容差。
