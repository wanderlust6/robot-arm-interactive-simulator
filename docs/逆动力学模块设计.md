# 平面机械臂逆动力学模块设计

## 1. 目标与范围

在现有 `代码与仿真/数学原型/dynamics.py` 的重力力矩模型上，增加可独立验证的完整逆动力学计算。输入关节位置、速度和加速度，输出每个转动关节为实现指定运动所需的驱动力矩。第一阶段不修改桌面 GUI，不模拟电机控制闭环。

## 2. 物理约定

- 机械臂为二维平面刚性串联转动关节，基座固定，x 向右、y 向上，重力沿 -y。
- 关节角为相对角，第一关节相对 x 轴，后续关节相对前一连杆；内部统一使用弧度、秒、米、千克、牛顿和牛顿米。
- 每根连杆用长度、质量、沿连杆轴线从近端关节到质心的距离，以及绕质心且垂直运动平面的转动惯量描述。
- 末端负载第一阶段建模为位于末端的点质量，不包含负载自身转动惯量或末端姿态约束。
- 关节力矩正方向为逆时针；正输出表示需要施加该方向的驱动力矩。重力补偿项应与现有 `gravity_torques` 的符号约定一致。
- 忽略摩擦、齿轮传动、柔性、间隙、接触力和电机限制。

## 3. 动力学方程

使用标准刚体逆动力学形式：

`tau = M(q) q_ddot + c(q, q_dot) + g(q)`

其中 `c` 表示所有速度相关的科氏/离心广义力矩向量。实现采用递归牛顿—欧拉算法（RNEA），通过前向递推计算各连杆角速度、角加速度与质心加速度，再通过反向递推汇总惯性力、重力和力矩至关节。算法应直接支持任意连杆数量，避免通过数值微分构造质量矩阵或科氏项。

## 4. 参数接口设计

保留现有 `PlanarArmDynamics` 和 `gravity_torques(joint_angles)`，避免破坏当前调用方。新增参数应向后兼容：

- `link_lengths`：正有限数值序列，单位 m。
- `link_masses`：非负有限数值序列，单位 kg；默认值沿用现有行为。
- `center_of_mass_fractions`：每根连杆质心相对长度比例，范围 [0, 1]，保留当前接口。
- `link_inertias`：每根连杆绕自身质心的平面转动惯量，单位 kg·m²。实现完整动力学时应明确默认值策略：如果用户未提供，应使用可解释的默认均匀细杆模型 `I = m L² / 12`；质量为零时惯量为零。文档必须说明这是建模假设，不是从真实机械臂自动识别出的参数。
- `payload_mass`：非负有限数值，单位 kg，默认 0。
- `gravity`：非负有限数值，单位 m/s²，默认 9.80665。

新增 `inverse_dynamics(joint_angles, joint_velocities, joint_accelerations)`，三个输入均须为与关节数量一致的一维有限数值序列，输出形状为 `(n,)` 的 NumPy 数组，单位 N·m。输入校验失败时抛出 `ValueError`。

## 5. 算法实现要求

- 先为新接口添加失败测试，再实现算法。
- 坐标变换与角度约定必须与 `PlanarArm.forward_kinematics` 一致。
- 明确处理基座固定、平面内转动轴统一垂直纸面的情况。
- 末端点负载的平动惯性和重力必须通过反向递推传回所有上游关节。
- 静止状态下 `inverse_dynamics(q, 0, 0)` 必须与 `gravity_torques(q)` 一致，允许明确设定的浮点容差。
- 零质量、零重力、零速度和零加速度等边界输入均需覆盖。

## 6. 验证矩阵

1. 单连杆水平静止：力矩等于 `g * (m * r_com + m_payload * L)`。
2. 单连杆竖直静止：重力力矩为零。
3. 单连杆零速度、非零角加速度：`tau = I_base * alpha`，其中 `I_base = I_com + m*r_com² + m_payload*L²`。
4. 任意姿态、零速度和零加速度：完整逆动力学与已有重力模型一致。
5. 两连杆静止与加速案例：使用独立手算或独立解析式核验，不只比较同一实现的两个函数。
6. 增加随机有限输入的输出形状、有限性检查，以及错误长度、NaN/Inf、负质量/负惯量等非法输入测试。
7. 运行数学原型全部测试、桌面应用全部测试和 `py_compile`。

## 7. 实施顺序

1. 检查现有动力学模块与测试，不覆盖用户未提交的更改。
2. 为参数与 `inverse_dynamics` 添加测试。
3. 实现递归牛顿—欧拉算法，并用可手算案例校验符号和惯量。
4. 更新数学原型 README、项目路线图或变更日志，准确标明功能状态。
5. 运行全部回归测试，检查 Git diff；不自动提交或推送。

## 8. 非目标

此阶段不增加 GUI 控件、不宣称已验证电机可执行性、不加入摩擦或执行器饱和、不将轨迹时间参数化与动力学约束耦合。上述内容留待核心逆动力学通过验证后再实施。


## 独立交叉验证补充

为降低逆动力学实现与自身测试逻辑相互一致、却共同存在错误的风险，新增一套独立数值参考：

- 从连杆质心和末端负载的位置雅可比矩阵构造广义质量矩阵；
- 通过中心有限差分计算质量矩阵对关节角的偏导，构造科氏/离心项；
- 通过重力势能对关节角的中心有限差分计算重力广义力；
- 将拉格朗日形式的参考力矩与递归牛顿—欧拉结果比较，覆盖 2、3、4 连杆模型的多组固定随机种子状态。

这套参考算法与主实现使用不同的动力学推导路径，但有限差分会引入数值误差，因此比较采用容差而不是要求逐位相等。该测试新增后必须在项目虚拟环境中实际运行并记录结果；在完成运行前，不将其标记为通过。
