# 开发路线图

> 当前状态：规划中。阶段完成情况应在功能通过验证后更新，不以时间经过自动视为完成。

## 阶段 0：需求与架构确认

- [x] 建立项目设计总档案
- [x] 明确以学习、算法理解和研究实验为主要目的
- [x] 明确先二维、后评估三维扩展的总体方向
- [ ] 确定第一版是否允许配置任意连杆数量
- [ ] 确定首版轨迹编辑方式
- [ ] 确定场景文件与实验记录格式
- [ ] 绘制低保真界面原型

**阶段产物：** 可追踪的设计文档、关键决策记录和第一版范围。

## 阶段 1：数学原型

- [ ] 定义二维串联机械臂的数据结构
- [ ] 实现正运动学
- [ ] 实现二维雅可比矩阵
- [ ] 用有限差分验证雅可比矩阵
- [ ] 构造奇异与非奇异测试姿态
- [ ] 建立自动化测试

**完成标准：** 核心公式有独立测试；基础姿态、边界姿态和数值误差均有记录。

## 阶段 2：逆运动学与约束

- [ ] 实现二维逆运动学
- [ ] 区分不可达目标与关节限位违规
- [ ] 明确角度单位、坐标系和容差约定
- [ ] 测试目标点接近工作空间边界的情况

**完成标准：** 对可达、不可达和边界目标有可复现测试案例。

## 阶段 3：桌面交互原型

- [ ] 验证 PySide6 与绘图方案
- [ ] 建立主窗口与中央工作区
- [ ] 支持选择与拖动关节/末端
- [ ] 显示和编辑基础参数
- [ ] 将模型状态、界面状态和计算逻辑分离

**完成标准：** 用户操作可以稳定更新模型；界面不承担核心数学计算。

## 阶段 4：轨迹、仿真与数据

- [ ] 定义几何路径与时间参数化轨迹的区别
- [ ] 实现轨迹采样与仿真控制
- [ ] 绘制关节角度、速度和末端轨迹
- [ ] 支持曲线与仿真时间联动
- [ ] 导出 CSV
- [ ] 记录模型参数、算法设置和仿真条件

**完成标准：** 导出数据可与仿真状态对应，实验可按记录重现。

## 阶段 5：奇异性分析与算法比较

- [ ] 实现雅可比矩阵秩与最小奇异值等指标
- [ ] 将几何奇异性与各类约束违规分别显示
- [ ] 实现基线求解方法
- [ ] 在验证后评估阻尼最小二乘等候选方法
- [ ] 设计公平、可复现的对照实验
- [ ] 记录算法的适用条件与局限性

**完成标准：** 结论由指标和实验数据支持，而不是只凭视觉观察。

## 阶段 6：扩展与发布评估

- [ ] 根据实际需求评估三连杆与冗余机械臂
- [ ] 评估是否需要动力学模型
- [ ] 设计三维模型和视图扩展接口
- [ ] 补齐文档、测试与安装说明
- [ ] 选择并添加适当的开源许可证
- [ ] 建立版本发布流程

**完成标准：** 扩展由明确的学习或研究问题驱动，并经过测试和文档审查。

## 阶段原则

每个阶段开始前，先确认目标、输入输出、验证方式和完成标准。若研究问题或技术验证改变了设计，应先更新设计档案和决策记录。
