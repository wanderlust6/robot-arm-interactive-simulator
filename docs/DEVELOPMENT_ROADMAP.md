# 开发路线图

> 当前状态：阶段 1 数学原型首轮验证完成；阶段 2 的解析逆运动学、关节限位筛选及组合场景测试已完成；阶段 3 桌面交互原型持续完善；阶段 4 已实现末端位置与关节角的实际状态记录、共享时间轴曲线和时间游标联动，速度/加速度曲线与 CSV 导出仍待实现。阶段完成情况以测试和文档证据为准，不以时间经过自动视为完成。

- [x] 测试目标点接近工作空间边界的情况
- [x] 实现独立关节角限位检查与逆运动学解筛选
- [x] 补充工作空间边界与关节限位组合场景的测试

**阶段进度：** 两连杆解析逆运动学、可达性判断、坐标/单位约定、工作空间边界测试和独立关节限位筛选均已实现，并有自动化测试覆盖。

- [x] 建立主窗口与中央工作区

## 阶段原则

每个阶段开始前，先确认目标、输入输出、验证方式和完成标准。若研究问题或技术验证改变了设计，应先更新设计档案和决策记录。
