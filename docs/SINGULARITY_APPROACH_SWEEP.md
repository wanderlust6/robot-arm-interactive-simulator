# 奇异位形接近方向与采样密度扫描

## 研究目的

已有实验中，基线 DLS 与奇异值自适应 DLS 在多数合成路径上的末端收敛率都接近 100%。因此，单看成功率不足以判断奇异位形附近的路径行为。本实验改变关节参考路径的接近方式与采样密度，并显式比较求解器输出与生成目标时使用的参考关节路径之间的差异。

## 实验设计

- 模型：两连杆平面机械臂，连杆长度 0.6 m 和 0.4 m。
- 工况：outer_q1_increasing、outer_q1_decreasing、outer_q1_curved_approach 三种伸直奇异位形附近路径，以及 inner_folded_crossing 折叠奇异位形穿越路径。
- 采样密度：每条路径 61、121、241 个点。
- 重复与配对：每个工况/采样密度 3 次确定性初值设置；两种方法使用相同设置。
- 方法：现有 DLS（阻尼 1e-3）与自适应 DLS（奇异值阈值 0.02、增益 0.05、阻尼上限 1.0）。
- 指标：收敛率、实际末端误差、最小奇异值、关节步长、离散二阶差分、参考关节偏差、参考分支不匹配点数及 P95 求解耗时。

路径目标由参考关节角经正运动学生成。关节步长与二阶差分计算前对求解器角度序列逐关节 unwrap，以避免 ±π 表示方式的跳变被误判为实际运动突跳。参考关节偏差按 2π 周期计算。分支不匹配只在参考与求解姿态都明显远离奇异分支边界时统计。

## 结果摘要

- 共 72 条重复序列、10,152 条逐点记录、24 个工况/采样密度/方法汇总组。
- 所有分组收敛率均为 100%；最差实际末端误差约为 9.95e-7 m，处于本实验 1e-6 m 的收敛容差附近。
- 采样点数从 61 增加到 241 时，相邻关节步长整体减小；这部分变化与采样间隔缩小一致，不能单独解释为算法变得更平滑。
- 参考关节路径穿过 q₂=0 或 q₂=π 后，求解器没有跟随参考分支穿过奇异位形，而是继续保持初始肘部分支。求解器仍能跟踪末端位置，但相对于生成关节路径出现明显偏差：伸直路径最大参考关节偏差约 0.564 rad，折叠路径约 0.866 rad。
- 参考分支不匹配共 4,968 个点，主要出现在参考轨迹穿过奇异位形之后。它表示求解器选择了另一组仍能实现末端目标的关节构型，不等于瞬时关节跳变，也不等于末端跟踪失败。
- 在 24 个汇总组的简单平均中，自适应 DLS 的平均最大离散二阶差分由约 0.00868 rad 降至约 0.00803 rad，但平均 P95 二阶差分由约 2.06e-4 rad 升至约 3.03e-4 rad；平均 P95 求解耗时由约 0.154 ms 升至约 0.178 ms。平均最大关节步长略有增加。不同采样密度下的聚合仅用于描述，不应替代逐工况比较。

## 结论

1. 末端位置收敛与关节参考轨迹复现是两个不同目标。位置 IK 可以在奇异位形另一侧选择另一肘部构型，仍然保持很小的末端误差。
2. 当前两种 DLS 在本实验中都达到了末端位置容差；自适应 DLS 没有显示出一致的综合优势，平滑性代理指标存在权衡，求解时间也更长。
3. 这组结果提示下一步应单独研究“分支意图保持”策略：在任务允许的情况下，明确是只要求末端位置连续，还是还要求跟随指定关节参考路径/肘部构型。不能把二者混为一个收敛标志。
4. 最小奇异值仍是局部几何指标，不应单独作为路径失败或真实安全风险的标签。
