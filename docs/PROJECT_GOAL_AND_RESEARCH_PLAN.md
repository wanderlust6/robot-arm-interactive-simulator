# 项目目标与研究路线

## 1. 项目定位

**暂定题目：面向多约束机械臂运动规划的可行性分析与改进**

本项目以算法研究为主线、交互式仿真软件为实验工具，研究机械臂在多种运动约束下的轨迹可行性分析与规划改进，并在条件具备后通过实体机械臂验证仿真结论。

当前定位是研究方向假设，不代表已经证明具有学术创新性。具体创新点须由文献调研、基线复现和实验结果确定。

## 2. 核心研究问题

给定机械臂模型、起终点或笛卡尔路径，以及关节角、速度、加速度、动力学等约束，如何判断规划轨迹是否可行；当规划失败或运动表现不理想时，如何定位主要原因，并选择合理的调整策略？

**首个切入点：奇异位形附近的运动规划。** 研究奇异性如何影响逆运动学求解、关节运动和约束满足情况，并评估相应的规划改进是否有效。奇异性是重点研究对象之一，而不是预设的唯一失败原因。

## 3. 项目要解决的实际问题

项目不以“生成并播放轨迹”为最终目标，而是逐步实现：

1. 判断规划结果是否满足明确的运动约束。
2. 对不可达目标、逆运动学不收敛、关节限位和运动约束超限等情况给出可验证的诊断。
3. 对比基线算法与改进方法，量化成功率、末端路径误差、运动时间、关节速度/加速度峰值等指标。
4. 保存配置、结果和实验摘要，使实验能够复现。
5. 在实体设备可用时，比较仿真预测与实际执行，分析模型误差和跟踪误差，并据此改进方法。

## 4. 阶段路线

### 阶段 A：可信的仿真研究原型

- 检查现有运动学、逆运动学、轨迹规划、动力学估算和约束检查的正确性。
- 明确每个指标的定义、单位、计算方法与适用假设。
- 将“几何奇异性监测”与“主动规避奇异性”区分开；后者需要算法实现和实验验证，不能仅凭状态显示宣称已经具备。
- 建立可复现的基线测试集和实验包。

**阶段交付：** 可重复运行的测试、基线结果、已知限制清单。

### 阶段 B：算法对比与改进

- 设计不同路径、约束和奇异性接近程度的测试场景。
- 复现并固定至少一种基线方法。
- 记录规划成功率、末端路径误差、规划/执行时间、关节运动指标和失败原因。
- 针对实验暴露的一个明确问题提出改进，并使用相同测试集公平比较。

**阶段交付：** 实验数据、对比图表、改进前后分析和研究报告初稿。

### 阶段 C：实体机械臂验证

- 根据实验室可用设备和接口，先执行低风险、简单且可测量的轨迹。
- 采集可用的关节状态、末端位置和时间数据。
- 比较仿真与实测的轨迹误差、时间差异和约束表现。
- 分析差异来源，必要时修正模型、规划或控制接口。

**阶段交付：** 仿真—实测对比、误差分析和进一步改进结果。

## 5. 项目范围与边界

当前优先做仿真，不立即扩展到视觉识别、复杂抓取、强化学习、完整自主机器人系统或未经需求验证的大规模三维场景。

软件界面和可视化以支持实验、诊断、对比和复现为目的。只有能够服务于核心研究问题的功能才优先开发。

实体机械臂是后续验证手段，不是项目当前成立的前提。进入实验室的理由应当是验证明确的算法假设，而不是单纯为了让软件连接硬件。

## 6. 评价标准

项目进展不以界面功能数量衡量，而以以下证据衡量：

- 数学模型和实现通过测试；
- 基线方法定义清楚且可复现；
- 实验指标有明确含义和单位；
- 对比实验能支持或否定研究假设；
- 改进结果在相同测试条件下可重复；
- 明确报告失败案例、适用条件和局限；
- 条件具备时，使用实体实验检验仿真结论。

## 7. 近期工作顺序

1. 审核现有代码与路线图，列出“已实现、仅监测、尚未实现、尚未验证”四类能力。
2. 完成奇异性指标与现有规划流程的正确性检查。
3. 建立可复现的测试场景和基线数据。
4. 通过文献调研确认已有方法及可能的研究缺口。
5. 选择一个具体可测的改进点，再决定是否实现新算法。
6. 完成仿真对比后，再规划实体机械臂实验。

## 8. 对外介绍时的表述原则

在没有相应实验数据前，只能说“正在研究”“已实现监测”或“计划验证”，不能声称已主动规避奇异位形、已证明算法优越，或已完成实体机械臂验证。项目展示应优先呈现问题定义、方法、实验设计、结果和局限，而不只是界面截图。
