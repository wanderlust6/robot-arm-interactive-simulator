# 轨迹规划算法重构设计

## 1. 设计原则

把“轨迹几何规划”“逆运动学求解”“轨迹时间参数化”拆成三个层次。它们解决不同问题，不应混成一组平级复选框。

- 几何规划：决定末端或关节要沿什么路径运动。
- 逆运动学：当任务要求末端走指定路径时，计算每个路径点对应的关节构型。
- 时间参数化：给几何路径分配时间，并检查关节速度、加速度、力矩等约束。

## 2. 用户可直接比较的规划方式

### A. 笛卡尔路径跟踪（保留现有主方法）

输入：用户绘制/编辑的末端路径。

做法：沿路径采样，对每个末端点连续求 IK，再对关节轨迹进行时间参数化。

不变量：末端应跟随指定的几何路径。

区别：末端路径受控；关节运动由 IK 分支和约束决定。

### B. 关节空间五次多项式规划（新增独立方法）

输入：起始关节构型和目标末端位置。先求目标位置的一组可达 IK 构型，再在起终关节角之间使用五次时间标度插值，端点速度和加速度为零。

不变量：关节角按指定的关节空间曲线变化，且端点静止。

区别：不强制末端沿用户绘制的路径走，末端会形成另一条曲线。这是最容易直观看出与笛卡尔路径跟踪差别的对照组。

约束：必须检查目标 IK 可达性、关节位置限位、速度、加速度和力矩；失败要报告原因，不得静默回退到笛卡尔方案。

### C. 笛卡尔路径 + 关节构型优化（作为策略，不冒充几何规划器）

在满足同一末端路径的前提下优化冗余自由度。包括：
- 连续性优先：每个点选择与上一个解最近的 IK 解。
- 参考构型偏置：在冗余自由度中尽量靠近用户指定/起始参考构型。
- 限位规避：通过约束或零空间目标远离关节限位；未启用限位时必须提示不适用，而不是退化成基线。
- 自适应 DLS：按雅可比最小奇异值调整阻尼，主要改善奇异位形附近的数值稳定性，不承诺普通区域一定产生不同几何轨迹。

### D. 最小关节运动（暂不宣称为已实现的独立规划器）

真正的整段最小运动应以整条轨迹为优化变量，优化例如
J = Σ ||q[k+1] - q[k]||²
并同时约束末端误差、关节限位和运动学可行性。当前逐点 least-squares 只是局部 IK 正则化，不等于整条轨迹全局最优。应先保留为实验策略并准确命名；后续再实现整段优化器与收敛/可行性诊断。

## 3. UI 与结果呈现

- 规划方式用单选：笛卡尔路径跟踪、关节空间五次规划。
- IK/构型策略作为笛卡尔方法的附加选项，不和几何规划方式混在一起。
- 结果对比必须保存每种方法的独立轨迹，并允许切换显示；不能只计算多条轨迹却只显示一个影子机械臂。
- 每个方案展示：末端实际路径、关节角曲线、最大末端偏差、累计关节运动、最小限位余量、最小奇异值、规划成功/失败原因。
- 不人为制造轨迹差异；同路径且同分支时，求解器轨迹接近是有效实验结果。

## 4. 接入顺序

1. 先接入并测试独立的关节空间五次规划，让它与现有笛卡尔跟踪形成明确的几何目标差异。
2. 修正界面选项的分类与适用条件。
3. 让所有已计算方案可被独立查看和比较。
4. 再实现整段最小关节运动优化，不能把逐点优化包装成全局最优。
