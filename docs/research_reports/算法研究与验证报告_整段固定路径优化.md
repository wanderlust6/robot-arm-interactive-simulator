# 整段固定末端路径优化：阶段验证报告

## 本次实现

新增 `代码与仿真/数学原型/pathwise_ik_optimizer.py`。优化变量是整段关节角序列 `q[0:N]`，目标函数同时惩罚二阶差分（关节轨迹离散平滑度）和一阶差分（关节总运动量）；每个采样点的正运动学末端位置都作为等式约束，关节角范围作为优化边界。末端目标点不由优化器修改。

新增 `代码与仿真/数学原型/test_pathwise_ik_optimizer.py` 与 `benchmark_pathwise_ik.py`。

## 测试环境与路径

- 模型：三关节平面串联臂，连杆长度 `[1.0, 0.8, 0.6]`。
- 数据性质：合成测试轨迹，不是用户手绘轨迹；通过关节锚点正运动学得到笛卡尔锚点，再以自然三次样条生成固定末端路径。
- 采样数：17。
- 关节限制：第一关节 ±150°、第二关节 ±145°、第三关节 ±150°。
- 优化器：SciPy SLSQP，最大迭代 250，端点误差验收阈值 2e-6（模型长度单位）。

## 实测结果

| 指标 | 连续 IK 初始轨迹 | 整段优化后 |
|---|---:|---:|
| 最大末端误差 | 8.16e-7 | 1.20e-13 |
| 关节路径长度（离散步长范数和） | 1.62470 rad | 1.68288 rad |
| 二阶差分平方和 | 0.017367 | 0.012407 |
| 三阶差分平方和 | 0.004528 | 0.003185 |
| 最大相邻关节向量步长 | 0.15802 rad | 0.15092 rad |
| 最小关节限位余量 | 76.34° | 97.03° |
| 优化耗时 | — | 1.168 s |
| SLSQP 迭代数 | — | 126 |

相较初始轨迹，二阶差分平方和下降约 28.6%，三阶差分平方和下降约 29.6%，最小限位余量增加约 20.7°；关节路径长度则增加约 3.6%。这说明优化确实改变了关节冗余分配，并在该测试案例中改善离散平滑度和限位余量，但不是所有指标同时变好。

## 自动化验证

- `python -m unittest test_pathwise_ik_optimizer -v`：1 项测试通过。
- `python -m unittest test_path_schemes -v`：现有桌面应用路径方案测试 4 项通过。
- 优化结果通过独立末端误差和关节边界验收。

## 结论与限制

1. 这是整段优化，不是对每个路径点分别调用 IK；全部 17 个末端目标在优化前后保持不变。
2. 当前是研究原型，尚未接入桌面应用的路径规划 UI，不能视为已交付的用户可选算法。
3. 仅验证一个 17 点合成案例，不能推断对用户绘制轨迹、奇异附近轨迹或紧限位轨迹普遍有效。
4. SLSQP 使用每点二维末端等式约束，轨迹点数增加后变量与约束规模都会增大；需要继续测试更密采样、失败回退、运行时间和初始化依赖。
5. 关节路径长度增加是当前权重下的真实代价；后续应做权重扫描与多路径验证，确定平滑性、运动量和限位余量的 Pareto 权衡，再决定是否暴露为正式算法选项。
