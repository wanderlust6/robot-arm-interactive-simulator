# 固定末端轨迹下的逆运动学算法研究路线

## 研究边界

本研究比较的是：给定完全相同的末端笛卡尔路径，怎样为路径上的每个点选择关节构型，使关节运动特性产生可解释差异。所有候选方法必须消费同一组末端目标点；禁止用关节空间插值替换末端路径，禁止为了显示差异而扰动目标点。

## 文献调研得到的方法族

1. **微分逆运动学基线**：雅可比伪逆、阻尼最小二乘（DLS）、自适应阻尼。适合连续跟踪与奇异附近的数值稳定性比较；阻尼参数变化未必造成可见关节轨迹差异。
2. **加权伪逆 / 加权最小范数**：通过关节权重改变关节运动分配，例如抑制某些关节的大幅运动。适合做有明确偏好、可解释的差异实验。
3. **零空间梯度投影**：在尽量不影响末端主任务的前提下，优化关节限位余量、参考姿态或可操作度。需要检查投影误差、步长和连续性，不能把数值近似下的“零空间”当作绝对无影响。
4. **任务优先级 / 分层控制**：末端跟踪为高优先级，限位规避等为低优先级；可处理多个次任务，但要明确任务优先级和奇异情况下的行为。
5. **约束优化 / QP / SQP**：将关节位置、速度、加速度约束和次目标写入优化问题。TRAC-IK 是现成例子，结合改进的数值 IK 与 SQP；其目标和求解过程不同于简单地给 DLS 换名字。
6. **整段路径逆运动学 / 轨迹级优化**：将整段关节序列作为优化变量，显式优化关节位移、速度、加速度、jerk 或可操作度，并约束每个时刻的末端点误差。这和逐点求解加单步正则化不是一回事。TORM 是沿给定末端路径优化关节轨迹的代表性研究方向。
7. **全局/随机搜索与混合优化**：例如全局优化产生候选，再用局部梯度法精修；可探索不同 IK 分支，但计算成本更高，必须与确定性基线公平比较。
8. **速度/加速度层冗余解析**：在速度或加速度层面分配冗余自由度，优化运动时间或动力学相关指标；这是后续扩展方向，不应与当前只含位置运动学的模型混为一谈。

## 针对当前项目的可执行筛选顺序

1. 先审查当前模型的自由度与任务维数。若机械臂自由度与末端约束维数相等，零空间维数可能为零；这时许多“冗余度优化”不能在保持末端位置/姿态完全不变的前提下自由调整关节。若当前仅约束二维末端位置而有三个转动关节，则存在局部冗余，但仍需验证雅可比秩与奇异位形。
2. 固定一条可达末端路径、同一起始关节构型、同一采样与限位，先比较加权伪逆、限位/参考姿态零空间投影与基线 DLS。
3. 再构建真正的整段轨迹优化基准：优化变量是整段 q[0:N]，约束每个样本的正运动学位置等于同一个目标点；目标函数分别测试总关节位移、速度平方、加速度平方/jerk 与限位余量。不可把逐点 least_squares 误称为全局轨迹优化。
4. 研究 QP/SQP 的约束处理能力，重点测试限位、速度、加速度以及接近奇异位形的可行性。
5. 每种方法报告：末端最大/RMS 误差、关节路径长度、速度/加速度/jerk、最小限位余量、失败率、求解时间、与基线的关节轨迹差异。只有在指标上有明确收益且约束达标，才进入 UI。
