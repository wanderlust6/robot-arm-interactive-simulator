# 二维机械臂数学原型

本目录实现二维平面串联机械臂的基础运动学，不依赖桌面 GUI。核心代码可独立测试，后续界面层应调用这些函数，而不是把公式写进绘图逻辑。

## 当前范围

- 任意数量的平面转动关节，连杆长度固定。
- 正运动学：计算基座、各关节及末端的位置。
- 末端位置雅可比矩阵：描述关节角微小变化与末端位置微小变化之间的局部线性关系。
- 输入校验与数值测试。
- 暂不包含逆运动学、关节限位、动力学、轨迹规划和 GUI。

## 坐标系与单位约定

- 基座位于二维坐标原点。
- \(x\) 轴向右，\(y\) 轴向上。
- 角度单位为弧度，正方向为逆时针。
- 每个关节角是相对前一根连杆的转角；第一关节角相对正 \(x\) 轴。
- 连杆长度必须是有限的正数；关节角必须是有限数值。
- 长度单位由使用者自行统一，例如全部使用米；代码不隐含指定长度单位。

## 数学定义

设有 \(n\) 根连杆，长度为 \(L_i\)，相对关节角为 \(q_i\)。第 \(i\) 根连杆的绝对方向为

\[
\phi_i = \sum_{k=1}^{i} q_k.
\]

基座位置为 \(p_0=(0,0)\)，第 \(i\) 个连杆末端位置为

\[
p_i = p_{i-1} +
\begin{bmatrix}
L_i\cos\phi_i\\
L_i\sin\phi_i
\end{bmatrix}.
\]

函数 `forward_kinematics(q)` 返回形状为 `(n + 1, 2)` 的 NumPy 数组，第一行是基座，最后一行是末端位置。

末端位置对关节角的雅可比矩阵定义为

\[
J(q) = \frac{\partial (x,y)}{\partial (q_1,\ldots,q_n)}
\in \mathbb{R}^{2\times n}.
\]

对于第 \(i\) 个关节，令从该关节位置指向末端的向量为 \(r_i=(r_{ix},r_{iy})\)，则对应雅可比列为

\[
J_i =
\begin{bmatrix}
-r_{iy}\\
r_{ix}
\end{bmatrix}.
\]

这是平面转动关节的二维速度关系：关节角速度为正时，末端相对于关节沿逆时针切向运动。函数 `jacobian(q)` 返回形状为 `(2, n)` 的数组。

## 运行与测试

需要 Python 3.10 或更新版本，以及 NumPy。测试使用 Python 自带的 `unittest`，不要求安装 pytest。

在本目录运行：

```powershell
python -m pip install -r requirements.txt
python -m unittest -v test_planar_arm
```

测试覆盖：

- 两连杆伸直、折转等可手算姿态；
- 三连杆正运动学输出形状；
- 雅可比矩阵的解析结果；
- 使用中心有限差分独立检查雅可比矩阵；
- 两连杆伸直奇异姿态与弯折非奇异姿态；
- 非法连杆长度、关节角数量不匹配和非有限输入。

有限差分检查比较的是末端位置对每个关节角的数值导数与解析雅可比矩阵。它能帮助发现符号、角度累积或索引错误，但不替代后续更广泛的验证。

## 最小示例

```python
import numpy as np
from planar_arm import PlanarArm

arm = PlanarArm([1.0, 1.0])
angles = [np.pi / 4, -np.pi / 3]

print("各关节位置：")
print(arm.forward_kinematics(angles))
print("末端位置雅可比矩阵：")
print(arm.jacobian(angles))
```

## 已知限制

- 只描述平面内的几何运动学，不模拟质量、惯量、重力、摩擦或关节转矩。
- 雅可比矩阵只针对末端的二维位置，不包括末端姿态。
- 当前奇异姿态测试针对两连杆平面机械臂；不能据此推断空间六自由度机械臂的全部奇异类型。
- 目前尚未实现逆运动学和工作空间可达性判定。
