# 桌面应用原型

这是基于 PySide6 的二维串联机械臂交互原型，复用 `数学原型` 中的正/逆运动学、关节限位与约束求解模块。

## 当前功能

- 支持 1–12 段平面串联机械臂，初始为三段、每段长度 1.0。
- 初始与重置姿态采用“上、右、上、右……”的阶梯排列；相对关节角按 `+90°、-90°` 交替。
- 增减连杆数量时保留已有连杆长度、关节角和关节限位；新增连杆长度默认为 1.0，角度按阶梯规律初始化。
- 使用滚轮缩放工作区视图，缩放以鼠标指针所在位置为中心；缩放范围为 0.2–5.0 倍。
- 支持编辑连杆长度与各关节角限位。
- 拖动末端目标点时调用任意段数数值逆运动学，并检查目标可达性和关节限位。
- 支持拖动中间关节；多段模型通过约束求解调整上游关节，并尽可能保持固定节点和连杆长度。
- 两段模型保留肘关节固定直线拖动功能。
- 可选择关节/连杆，并查看节点位置、角度与固定状态。
- 求解状态以颜色和文字共同提示。
- 仿真曲线支持独立设置 X 轴和 Y 轴；Y 轴可添加多条曲线，包含节点位置、速度、加速度、关节相对角、连杆绝对方向、角速度和角加速度。
- 多条曲线物理量不同时，可选择分图显示；运动学速度和加速度由仿真采样数据数值微分估算。
- 数据分析窗口可将当前选择的列导出为 CSV，列名使用变量标签，文件采用 UTF-8 BOM 编码以便电子表格软件识别中文。
- 曲线窗口可将当前绘图控件导出为 PNG、JPEG 或 BMP 图像；导出图像尺寸取决于当前控件显示尺寸。

## 运行方式

在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r "代码与仿真\桌面应用\requirements.txt"
.\.venv\Scripts\python.exe "代码与仿真\桌面应用\app.py"
```

## 测试

在项目根目录运行数学原型和桌面交互测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s "代码与仿真\数学原型" -p "test_*.py"
$env:QT_QPA_PLATFORM = "offscreen"
.\.venv\Scripts\python.exe -m unittest discover -s "代码与仿真\桌面应用" -p "test_*.py"
```

## 当前边界

这是交互原型，不是完整仿真器。关节速度、关节加速度、末端速度/加速度曲线，完整实验条件记录，场景保存/加载、负载对象、速度约束、动力学、碰撞检测和三维模型尚未实现。数据导出目前只包含数据窗口中已选择的列；图像导出为当前绘图控件的栅格截图，分辨率受控件显示尺寸限制。关节限位与逆运动学用于几何运动学演示，不代表真实机械臂的安全控制系统。
