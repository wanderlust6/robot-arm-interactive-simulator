# 桌面应用原型

这是基于 PySide6 的二维串联机械臂交互原型，复用 `数学原型` 中的正/逆运动学、关节限位与约束求解模块。

## 当前功能

- 支持 1–12 段平面串联机械臂，初始为三段、每段长度 1.0。
- 初始与重置姿态采用“上、右、上、右……”的阶梯排列；相对关节角按 `+90°、-90°` 交替。
- 增减连杆数量时保留已有连杆长度、关节角和关节限位；新增连杆长度默认为 1.0，角度按阶梯规律初始化。
- 使用滚轮缩放工作区视图，缩放以鼠标指针所在位置为中心；缩放范围为 0.2–5.0 倍。
- 支持编辑连杆长度与各关节角限位。
- 拖动末端目标点时调用任意段数数值逆运动学，并检查目标可达性和关节限位。
- 支持拖动中间关节；多段模型通过约束求解调整上游关节，并尽可能保持固定节点和连杆长度。
- 两段模型保留肘关节固定直线拖动功能。
- 可选择关节/连杆，并查看节点位置、角度与固定状态。
- 求解状态以颜色和文字共同提示。
- 仿真曲线支持独立设置 X 轴和 Y 轴；Y 轴可添加多条曲线，包含节点位置、速度、加速度、关节相对角、连杆绝对方向、角速度和角加速度。
- 多条曲线物理量不同时，可选择分图显示。节点速度/加速度由**雅可比 × 解析角速度/角加速度**求得，关节角速度/角加速度取自规划样条解析导数；只有缺少这些解析量时才退回数值微分。
- 支持查看各关节驱动力矩—时间曲线，并在“机械臂设置”中调整各连杆质量、质心比例、绕质心的平面转动惯量与末端负载质量。
- 默认质心比例为 0.5，默认转动惯量按均匀细杆公式 `I = mL²/12` 初始化；质心比例范围为 0–1，转动惯量控件允许用户按具体刚体模型设置。
- 更改质量、质心、转动惯量或负载后，会基于已记录的关节轨迹重新计算理论力矩；力矩计算使用展开后的关节角序列估计角速度与角加速度。
- 仿真面板支持两种轨迹时间模式：自动规划时间（沿选定笛卡尔路径进行连续数值逆运动学，并自动延长时间以满足角速度、角加速度和理论力矩上限）以及指定总时间（按用户给定时间运行，再使用可执行性检查评估约束）。自动模式受当前几何路径、逆运动学收敛和关节限位影响。
- 仿真面板提供轨迹可执行性初步检查，可设置各关节角速度、角加速度和理论驱动力矩上限，并报告超限指标与涉及的关节；结果还列出每个关节三项指标的峰值及其发生时刻。角速度/角加速度通过采样轨迹数值微分估算，至少需要 3 个采样点。
- 数据分析窗口可将当前选择的列导出为 CSV，列名使用变量标签，文件采用 UTF-8 BOM 编码以便电子表格软件识别中文。
- 曲线窗口可将当前绘图控件导出为 PNG、JPEG 或 BMP 图像；导出图像尺寸取决于当前控件显示尺寸。

## 当前边界

这是交互原型，不是完整仿真器。动力学目前仅计算理想刚性平面模型的关节力矩，不包含摩擦、接触、碰撞、电机饱和、传动效率或控制器动力学；速度与加速度由离散采样数值微分估算，不能直接代表真实机械臂的实测值。完整实验条件记录、场景保存/加载、速度约束、碰撞检测和三维模型尚未实现。数据导出目前只包含数据窗口中已选择的列；图像导出为当前绘图控件的栅格截图，分辨率受控件显示尺寸限制。关节限位与逆运动学用于几何运动学演示，不代表真实机械臂的安全控制系统。

## 速度与加速度曲线

关节角速度与角加速度不是对记录角度做差分，而是取**播放样条的解析一阶/二阶导数**。因此曲线是否平滑取决于重建轨迹的连续性：

- 播放样条是分段五次 Hermite，同时匹配规划给出的关节角、角速度、角加速度，二阶导连续（C²）。关节角加速度不会在每个采样节点跳变。
- 曲线取数时优先使用**记录下来的解析角速度/角加速度**（主方案与每个叠加方案各自保存），不再对记录角度做两次数值微分。数值微分会被墙钟采样的时间抖动放大：实测同一段轨迹，数值微分把加速度峰值从 0.234 抬到 3.45（约 15 倍），相邻跳变从 0.010 抬到 0.820。
- 规划器的关节路径插值使用 C² 三次样条。此前用的是 C¹ 的 PCHIP，二阶导在全部路径节点不连续，是加速度曲线抖动的另一主因。
- 记录角速度/角加速度时会把时刻截断到样条定义域。播放总时长取各方案最大值，可能超过主方案时长；越界求值会外插，使加速度随超出时间线性增长，而末端其实早已停在终点。
- 拐点停速处的加速度变化是"停住再起步"的物理结果，予以保留，不做平滑。
- **播放按固定步长推进**（定时器周期 × 播放倍速），不按墙钟实际耗时推进。原先墙钟一旦被 UI 卡顿打断，采样间隔会在 4–62 ms 之间跳变；记录点疏密不均会让折线顶点忽密忽疏（看起来像数据在抖），也会让任何基于相邻差分的指标失真。掉帧时现在只是播放落后于墙钟，数据仍落在均匀网格上。
- 数据窗口的「诊断当前列」会先**把序列重采样到均匀网格**再计算锯齿指标。直接对不等间隔序列做二阶差分，会把采样疏密误判成抖动（实测同一条平滑曲线：原始指标 15.2%、重采样后 0.25%）。
- **绘图采样抽取**：当一条曲线的点数超过"像素列数 × 2"时，绘制时按像素列只保留该列的**最小值和最大值**，避免把上千个点硬挤进几百像素。这**不是滤波**——数值、峰值和导出数据都不变，极值包络完整保留；发生抽取时图表右上角标注"显示：按像素列抽取极值（数值未改）"。它的作用是"不制造假锯齿"，而不是"把抖动的曲线画平"：真实的高频成分会表现为更粗的包络带。
- **曲线显示平滑（可选，默认关闭）**：模拟面板的「曲线显示平滑（仅影响绘图）」对画到图上的曲线做零相位 Savitzky-Golay 滤波，窗口 5–101 点。它**只影响绘图**：数据表格、CSV 导出、可执行性检查与「诊断当前列」始终使用原始数值；启用时图表右上角标注"显示已平滑"。实测窗口 31 时二阶差分均值由 0.1135 降到 0.0019（约 60 倍），但峰值同时由 1.065 降到 1.002 —— **峰值会被削掉，所以不能用平滑后的曲线判断约束是否满足**。需要真正平滑的轨迹时应启用 jerk 上限。

关节力矩与轨迹可执行性检查同样优先使用解析导数；只有在缺少解析导数（例如加载不含该字段的旧数据）时才退回数值微分。

**参考构型偏置**的偏置项只在该路径点的前 2 次迭代施加。若一直施加到收敛，每个点会在零空间里直接跳到参考构型，相邻路径点的关节跳变可达 0.186 rad，时间标定后角加速度峰值升到 5.6 rad/s²，曲线上表现为抖动。限制迭代次数后路径最大步长降到 0.023 rad，而与基线的关节差异基本不变（17.8° → 17.35°）。

注意：**未启用任何速度/加速度/力矩上限时，规划器会把整条路径放在 1.0 s 内完成**，加速度与加加速度按 1/T²、1/T³ 放大，曲线看起来会很"猛"。这是规划时间设置的结果，不是数值噪声。需要平缓的运动时请启用角速度或角加速度上限。

**加速度曲线仍有较大起伏时，通常是因为没有约束加加速度（jerk）。** 规划器只保证 `|q̈| ≤ 上限`，不约束 q̈ 变化的快慢；在 100 Hz 采样下，较短的可行时长会让相邻样本的加速度差很大。实测同一路径：

| 配置 | 总时长 | 加速度幅值 | 加速度相邻跳变 |
|---|---:|---:|---:|
| jerk 关闭 | 6.66 s | 7.51 | 12.36 |
| jerk ≤ 50 rad/s³ | 16.85 s | 1.35 | 0.84 |
| jerk ≤ 20 rad/s³ | 22.94 s | 0.76 | 0.35 |

启用 jerk 上限可把加速度的相邻跳变降低约一个数量级，代价是总时长变长。若需要平滑的加速度/力矩曲线，应优先启用 jerk 上限。

## 路径方案与叠加对比

“模拟运行”面板的“路径方案（可多选）”提供四种方案，可任意多选后点击“准备”。

所有方案消费**同一条末端笛卡尔路径**与**同一初始姿态**，只改变关节构型分配（冗余分解）。因此正确结果是“末端轨迹相同、机械臂形状不同”，而不是末端走出不同路线。

| 方案 | 做法 | 何时与基线不同 |
|---|---|---|
| 连续性优先（蓝绿） | 以上一采样点为初值的 DLS 基线 | —（基线本身） |
| 参考构型偏置（橙） | 零空间内向固定参考构型逐步靠拢（每个路径点只偏置前几次迭代） | 只要有冗余自由度就会不同 |
| 加权关节分配（紫） | 加权最小范数，权重大的关节更“懒” | 总是不同 |
| 关节限位规避（红） | 零空间内远离限位的排斥梯度 | 需要先启用关节限位，否则标记为“不适用” |

显示规则：

- 主方案（第一个勾选的方案）作为实色主机械臂；其余方案以各自颜色的半透明机械臂**同时叠加**绘制，右侧显示图例与状态。
- 播放按**各方案自身的时间轴**推进。各方案总时长不同，因此同一时刻它们处在路径的不同进度上：较快的方案更早到达终点并停在那里。这是“总时间不同”应有的可见结果。
- 规划失败或不适用（例如未启用限位时的限位规避）的方案只在图例中标注，不绘制机械臂，不用插值或主机械臂姿态伪造结果。
- **姿态跟随**：点击“准备”后若再拖动末端或关节，原规划作废，叠加臂改为按**当前末端目标**逐点重新求解并跟着你的调整移动（图例标注“跟随当前姿态”）。这时的叠加臂是单点试算，不代表已规划好的整条轨迹；重新点击“准备”即恢复规划轨迹与播放。
- 若某个方案在当前姿态下无解（例如与固定节点或限位冲突），图例标注“当前姿态无解”，该臂不绘制。
- 与主方案关节路径差异小于 0.01° 的方案在图例中标注“与主方案一致”，避免误以为是绘图问题。
- 所有方案在路径起点被固定为同一姿态，因此 t=0 时各臂重合，差异从路径中段开始显现。
- 规划结果文本会给出每个方案相对主方案的最大关节角差。该指标在**统一的路径采样网格**上计算，与播放时序无关，是判断“构型到底差多少”的可靠依据。
- 绘图窗口的坐标轴设置（X/Y）与数据窗口的“添加数据列”中的“路径方案”下拉框，只列出**当前已规划的方案**（按准备时的顺序与显示名），不再固定为两项；绘制节点/关节曲线时它决定使用哪个方案的关节轨迹。
- 方案诊断类曲线（末端误差、最小奇异值、条件数）的方案由变量自身的索引决定；即使下拉框选了别的方案，列标题也会显示实际数据所属的方案，不会错标。

### 两种播放对齐方式的取舍

“按时间”和“按路径进度”不可能同时满足：

- **按时间**（当前实现）：能看到总时间差异，但同一帧里各臂停在路径的不同位置，构型对比会被位置差干扰。
- **按路径进度**：同一帧各臂处在同一末端目标点，只差构型；但总时间差异完全不可见，末端永远同步。

当前选择按时间，因为它忠于“各方案用时不同”这一事实；构型差异改由规划结果中的“与主方案最大关节差”和诊断曲线表达。

### 为什么“奇异值自适应阻尼 DLS”与“整段平滑优化”不在界面里

**奇异值自适应阻尼**：阻尼仅在 `σ_min < 阈值` 时增加。三连杆常规路径的 σ_min 远大于阈值，阻尼项恒为 0，求解步与基线完全相同，实测关节差约 `4e-8°`（浮点噪声）。它只在接近奇异位形时才有意义，不适合与基线并列成常规选项。实现保留在 `数学原型/compare_damping_strategies.py` 的 `adaptive_ik`，供奇异性专项测试与历史报告复现。

**整段平滑优化**：该方案对整条关节路径做 SLSQP 联合优化，需要与采样点数同量级的优化变量。实测在界面默认的 240 个采样点上：

- 规划耗时约 **199 s**（含 600 次迭代上限），会冻结窗口数分钟；
- 二阶差分平方和仅降低约 **8.8%**，最大关节差约 4.3°。

把优化节点降到 41–121 个再做插值回全分辨率也不可行：插值后末端误差达 1e-4 m，必须逐点重跑 IK 修正，而 IK 投影会把关节构型拉回最小范数解，把优化收益基本抹平（实测二阶差分比 0.93–1.79）。

因此该方案作为**离线研究工具**保留：`数学原型/pathwise_ik_optimizer.py`、`benchmark_pathwise_ik.py`、`validate_pathwise_ik.py`，不进入同步规划界面。若日后要接入，正确做法是把整段规划放到后台工作线程，而不是在 UI 线程里同步等待。

## 自动实验与算法对比

点击工具栏中的“自动实验与算法对比”，再点击“运行自动实验”。程序会生成内边界、外边界和普通可达区三个工况，对当前 DLS 与奇异值自适应 DLS 进行配对运行，并在表格中显示序列成功、点成功率、不可达目标数、求解失败数、最大末端误差和 P95 耗时。

每次运行会保存到项目根目录下的 `数据与实验/自动实验批次/桌面运行-时间戳`，包含每工况的结果以及 `batch_summary.json` / `batch_summary.csv`。这是小规模研究演示，不代表实机性能，也不预设某种算法更优。

注意：该对话框目前使用固定模型（两连杆 0.6 m / 0.4 m、9 个目标点、固定随机种子），**不读取主界面当前的机械臂参数**。
