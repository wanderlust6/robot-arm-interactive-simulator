# 机械臂交互式仿真平台
**Interactive Robot Arm Simulation Platform**

面向机械臂奇异性问题的交互式仿真、逆运动学算法比较与实验研究平台。当前以二维平面串联机械臂为对象，重点建立可复现的实验流程，分析不同逆运动学方法在末端跟踪、关节连续性、约束满足、奇异性表现与计算开销上的权衡。

## 当前状态

- 提供基于 Python、NumPy、PySide6 的桌面交互仿真原型。
- 支持机械臂连杆数量与参数编辑、末端目标和路径点交互、轨迹规划与播放。
- 支持运动学及部分动力学数据、奇异性诊断、曲线查看与数据导出。
- 数学原型和实验脚本覆盖数值逆运动学、连续解选择、DLS 相关方法及奇异性风险分析。
- 支持保存与加载实验数据包；具体功能以当前代码实现为准。
- 自动实验设计、全面统一的算法评价与自适应算法选择仍在逐步开发中。

研究结论以实验记录为准。当前已有实验不支持“某种算法在所有工况下普遍更优”的结论；末端位置收敛也不等于复现指定关节构型或满足所有运动约束。项目目前是仿真与研究原型，不代表实机验证或安全认证。

## 研究目标

1. **实验设计**：构造接近或穿越奇异位形、初值扰动、采样密度变化及关节限位等代表性工况。
2. **公平比较**：在一致模型、目标轨迹和评价规则下比较候选逆运动学方法。
3. **多指标分析**：结合末端误差、收敛情况、关节运动连续性、约束违反、奇异性指标和计算耗时解释结果。
4. **算法推荐探索**：在积累可复现证据后，研究针对任务与工况的可解释算法选择策略。

## 环境与运行

建议使用 Python 3.11 或项目实际依赖所支持的版本。

在项目根目录的 PowerShell 中运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r "代码与仿真\桌面应用\requirements.txt"
.\.venv\Scripts\python.exe "代码与仿真\桌面应用\app.py"
```

如果数学原型或实验脚本有独立依赖，请参考对应目录的 README 和依赖文件。

## 测试

桌面应用测试示例：

```powershell
Set-Location "代码与仿真\桌面应用"
python -m unittest discover -s . -p "test_*.py" -v
```

数学原型测试请根据该目录中的测试文件和 README 执行。GUI 测试在无显示环境下可能需要设置 Qt 的 offscreen 平台插件。

## 研究原则

- 不预设任何算法是普遍最优的。
- 区分末端任务误差、关节构型分支、运动连续性和约束满足。
- 记录实验配置、算法参数、采样策略、指标定义及局限，保证结果可追溯。
- 明确区分仿真假设、研究阈值与真实设备约束。
- 在证据充分之前，不将实验性推荐或切换策略当作实机控制方案。
