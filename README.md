# 机械臂交互式仿真平台
**Interactive Robot Arm Simulation Platform**

一个面向机器人学学习与研究实验的轻量级桌面仿真软件。项目计划从二维平面机械臂开始，逐步实现运动学、轨迹交互、奇异性分析和实验数据可视化，并为后续三维扩展保留清晰的架构边界。

> **项目状态：二维多段机械臂交互原型开发中。** 当前支持 1–12 段平面串联机械臂、动态连杆/关节限位参数、末端目标数值逆运动学、中间关节拖动及鼠标滚轮缩放；初始姿态为“上、右、上”的阶梯排列。两段模型保留末端固定直线约束的肘关节拖动。核心数学测试与桌面交互测试均有自动化覆盖。完整轨迹仿真、图表联动和数据导出仍未完成。
> 功能状态以自动化测试及设计总档案为准。

## 项目目标

- 通过可交互的机械臂模型理解运动学与机器人控制中的核心概念。
- 将工作区中的机械臂操作与属性面板、数据曲线和仿真时间联动。
- 对关键数学算法建立独立测试和可复现实验，而不只依赖动画效果判断正确性。
- 以二维模型为起点，逐步扩展到更复杂的机械臂模型与三维视图。

## 设计原则

1. **先验证数学，再扩展界面。** 先建立可独立测试的数学原型，再逐步实现桌面交互。
2. **模型与视图分离。** 模型维度描述真实运动自由度，视图模式只描述观察方式；两者不能混为一谈。
3. **计算与界面分离。** 核心算法不依赖 GUI 绘制代码，便于测试、复用和验证。
4. **区分物理概念。** 奇异位形、关节限位、速度超限、目标不可达和动力学约束违反分别处理。
5. **实验可追溯。** 记录模型参数、算法设置、仿真条件和结果，保证结论可复现。
6. **功能渐进交付。** 优先完成小而正确的核心功能，不以功能数量代替质量。

## 开发路线

1. **数学原型**：实现二维机械臂正运动学、雅可比矩阵与两连杆解析逆运动学，并用可手算案例验证。
2. **数值验证**：测试逆运动学、可达性、奇异位形与数值容差。
3. **桌面交互**：搭建工作区、对象选择、参数编辑和仿真控制。
4. **轨迹与数据**：加入轨迹采样、图表联动、数据导出和可复现实验。
5. **算法对比**：在明确的实验条件下比较候选奇异性处理方法。
6. **按研究需要扩展**：再决定是否加入冗余机械臂、动力学或三维能力。

详细安排见[开发路线图](docs/DEVELOPMENT_ROADMAP.md)。

## 运行桌面原型

首次使用时，在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r "代码与仿真\桌面应用\requirements.txt"
.\.venv\Scripts\python.exe "代码与仿真\桌面应用\app.py"
```

## 当前状态与贡献

当前数学原型具备正运动学、雅可比矩阵、两连杆解析逆运动学、任意段数阻尼最小二乘逆运动学、关节限位筛选及两段模型肘关节约束拖动求解。桌面原型支持 1–12 段连杆数量切换、动态长度与关节限位编辑、末端目标拖动，以及多段模型任意中间关节拖动；中间关节拖动通过求解其上游关节实现位置跟随，同时保持连杆长度和下游相对关节角不变。下一阶段继续实现轨迹编辑、仿真时间与曲线联动。提交新功能前，请说明其目的、验证方式以及对现有设计的影响。详见 [CONTRIBUTING.md](CONTRIBUTING.md)。
