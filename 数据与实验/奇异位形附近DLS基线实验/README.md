# 奇异位形附近 DLS 基线实验包

本目录包含三个可分别导入桌面仿真软件的实验包：
1. 01_参考姿态：目标构型相对远离完全伸直位形。
2. 02_接近奇异：目标接近最大伸展半径。
3. 03_完全伸直：目标处于完全伸直的奇异边界。

## 导入方法
打开桌面应用，点击工具栏“加载实验包”，依次选择每个子目录中的 experiment.json。加载后先观察配置和记录数据，再点击“准备”重新规划。建议每个场景重复运行并记录状态提示。

每个包包含 experiment.json（配置）、results.csv（预先计算的仿真记录）、summary.json（统计摘要）和 README.md（测试步骤）。

注意：这是仿真基线，不是实体机械臂数据。实验包不主动规避奇异性，也不预设哪个场景一定失败；其目的是让你直观看到现有算法在不同目标条件下的行为，为后续可复现对比建立起点。
