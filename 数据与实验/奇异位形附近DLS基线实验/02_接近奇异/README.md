# 02_接近奇异

## 实验目的
接近奇异场景：目标接近最大伸展半径，观察现有 DLS 的误差与收敛表现。

## 如何测试
1. 在桌面应用中点击“加载实验包”，选择本目录中的 experiment.json。
2. 观察当前机械臂姿态、路径锚点和已记录的曲线数据。
3. 点击“准备”，让当前版本重新规划同一路径。
4. 记录规划是否成功、状态提示、奇异性指标及轨迹约束结果。
5. 对比三个场景；不要仅凭单次运行判定算法优劣。

## 场景参数
- 连杆长度：0.60 m、0.40 m
- 起始关节角：35°、35°
- 目标相对第二关节角：5.0°
- 路径：起点末端到目标末端的笛卡尔直线，241 个输入路径点
- 规划成功标志：True
- 规划器信息：已找到满足所设速度、加速度、力矩、末端线速度和角加加速度上限的笛卡尔路径轨迹。
- 记录采样数：480
- 记录时长：3.0000 s

## 重要限制
这是二维仿真实验，不是实体机械臂测试。results.csv 是预先计算的规划记录；重新点击“准备”后，软件会根据当前代码重新规划。当前规划器没有显式主动规避奇异位形，本实验只建立基线，不预设结论。
