How to read this page
  • Joint angle plots compare each method at the same path sample index.
  • The singular-value plot indicates local Jacobian conditioning; a smaller value signals proximity to a rank-deficient configuration, relative to this arm and task.
  • The joint-step plot shows the Euclidean change between adjacent joint-angle samples. Dots mark each method's maximum step.
  • These are synthetic numerical IK results, not physical robot measurements. Joint step depends on sample spacing, and it is not the same as velocity or acceleration.
  • Endpoint errors are close to numerical tolerance in these tests, so tiny differences should not be interpreted as a meaningful accuracy advantage.
