Reading notes
  • Endpoint error and convergence are correctness checks; compare continuity metrics only when these are comparable.
  • Joint step and discrete second difference depend on sampling density. Compare methods at the same path and point count.
  • Minimum singular value measures local Jacobian conditioning; it does not by itself prove the solver will fail.
  • Timing varies with machine load. This dashboard is based on synthetic reachable targets, not physical robot measurements.
  • The current candidate has not been integrated into the desktop application.
