# DLS 与奇异值自适应 DLS 对比演示包

## 导入方式
1. 打开机械臂交互式仿真平台。
2. 点击工具栏“加载实验”，选择本文件夹中的 `experiment.json`。
3. 在“模拟运行”面板把“求解方式”改为“对比两种算法（显示影子机械臂）”。
4. 点击“准备”，再点击“运行”。
5. 对比蓝/绿色主机械臂与橙色影子机械臂。

## 场景设计
- 三段平面串联机械臂，连杆长度均为 1.0 m。
- 初始姿态接近完全伸直的奇异位形。
- 路径在外工作空间边界附近往返，共 9 个路径锚点。
- `results.csv` 只有表头，导入后重新规划，不使用伪造的预先计算结果。

## 已知验证结果
本包已通过桌面应用实际导入并调用规划流程。两种算法均成功，最大末端误差均约为 `6.94e-6 m`，规划时长均为 `1.00 s`，两条关节轨迹最大差异约为 `5.13e-9 rad`。因此动画会几乎完全重合；这正是当前对比实现需要进一步改进的证据，不是你看错了。

更完整的验证与解释见 `对比诊断记录.md`。
